# ACS Fixture Hello

This repository now contains a basic Next.js web app scaffold for a future stock return calculator.

## Current scope

- Uses the Next.js App Router.
- Includes a minimal landing page that positions the app for stock return calculations and future analytics features.
- Keeps the structure intentionally small so the first calculator, richer inputs, and charts can be added incrementally.

## Getting started

1. Install dependencies:

	```bash
	npm install
	```

2. Start the development server:

	```bash
	npm run dev
	```

3. Open http://localhost:3000 in your browser.

## Available scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run start` runs the production server.
